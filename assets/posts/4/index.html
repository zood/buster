Now using OpenStreetMap!

It's been a long time coming, but Zood Location now uses data from OpenStreetMap served by OpenFreeMap and rendered with the MapLibre SDK.

The tile style isn't exactly the same as before, but it's close enough and after some time with it, I even prefer it to the previous style.

The only downside is that the APK is now significantly larger because of all the MapLibre code.
